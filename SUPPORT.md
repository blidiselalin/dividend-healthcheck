# Support

DividendScope is an educational analytics application in a controlled public beta. Support capacity is limited.

| Channel | Use for |
|---|---|
| GitHub issues | Non-sensitive, reproducible bugs and feature requests |
| General contact | Usage questions and beta access requests: `[OWNER ACTION REQUIRED: GENERAL_CONTACT_EMAIL]` |
| Privacy contact | Export, correction, deletion, restriction, account closure: `[OWNER ACTION REQUIRED: PRIVACY_CONTACT_EMAIL]` |
| Security contact | Private vulnerability reports only — see [SECURITY.md](SECURITY.md) |

Public application: `[OWNER ACTION REQUIRED: PUBLIC_APPLICATION_URL]`  
Repository: `[OWNER ACTION REQUIRED: GITHUB_REPOSITORY_URL]`

## How to ask usage questions

Email the general contact with:

- What you were trying to do
- Whether you used the public demo or an approved real portfolio
- Browser and whether you run the hosted app or a local/Docker copy

Do not attach real broker statements or portfolio exports to public issues.

## How to report reproducible bugs

Open a GitHub issue only after removing:

- Portfolio values and holdings detail
- Account identifiers and email addresses you do not want public
- OAuth details, cookies, and tokens
- Broker statements and import files
- Secrets and environment values

Include reproduction steps, expected vs actual behavior, and whether the issue appears in the public demo or an authenticated session.

## How to request access to the beta

Real portfolio access is invite-only. Use the in-app access-request flow when available, or email `[OWNER ACTION REQUIRED: GENERAL_CONTACT_EMAIL]`.

The public demo, when enabled, uses sample data only and does not require portfolio approval.

## How to request data export or deletion

Email `[OWNER ACTION REQUIRED: PRIVACY_CONTACT_EMAIL]` with:

- The email address on the account
- The request type (access, export, correction, deletion, restriction, objection, or account closure)

Identity verification may be required. Deleted data may remain in protected backups until backup retention expires. See [PRIVACY.md](PRIVACY.md).

## How to report security issues privately

Follow [SECURITY.md](SECURITY.md). Never file a public issue for a suspected vulnerability.

## Expected beta response targets

These are cautious targets, not guarantees:

| Request type | Target |
|---|---|
| Security acknowledgement | 5 business days |
| Non-sensitive bug triage | Best effort during the beta |
| Access / privacy requests | Best effort; legal timelines may apply once confirmed by the owner |

## Unsupported requests

The beta support channels do not provide:

- Personal investment recommendations
- Tax calculations for filing
- Broker account recovery
- Urgent trading decisions
- Guaranteed corrections of third-party market data
- Review of real broker statements attached to public GitHub issues
