# DividendScope public beta scope

This document defines what **v0.1.0-beta.1** includes and excludes.

Release type:

- Public product demo (sample data)
- Invite-only access to real portfolios
- Pre-release / public beta
- Educational analytics application

## Included

- Public sample portfolio for product exploration
- Google authentication
- Invite-only real portfolio access
- Manual holdings
- Existing supported broker-file imports after authentication
- Dividend income analysis
- Portfolio health indicators
- Research views
- Data-source and freshness labels where the application already surfaces them
- Support and privacy request process (documented)

## Excluded

- Automatic IBKR account synchronization
- Trading or order execution
- Personalized financial advice
- Payments or subscriptions
- Guaranteed uptime
- Guaranteed market-data accuracy
- Anonymous real-file upload
- Public sharing of real portfolios
- Unrestricted registration for real portfolios

## Beta success criteria

- A new visitor understands the product without assistance.
- An approved user can create a portfolio.
- Imported data remains isolated to that user.
- Received and estimated dividends are distinguishable.
- Users can find support, privacy, and security information.
- A tested backup and restore process exists (operator documentation in a later PR).
- Critical tests and security checks pass.
